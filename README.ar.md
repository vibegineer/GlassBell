<h1 align="center">GlassBell</h1>

<p align="center" dir="rtl">إعلامات كل التطبيقات في شكل لافتات زجاجية سريعة على طريقة macOS. لنظام Windows 11.</p>

<p align="center"><a href="README.md">English</a> · <a href="README.zh.md">中文</a> · <a href="README.hi.md">हिन्दी</a> · <a href="README.es.md">Español</a> · <b>العربية</b> · <a href="README.ru.md">Русский</a></p>

<div dir="rtl">

يعمل GlassBell في الخلفية، ويلتقط كل إعلام يصل إلى Windows ويعرضه في شكل لافتة زجاجية في الزاوية العلوية اليمنى من الشاشة: عدسة تحني الخلفية عند الحواف، وحافة ملوّنة، ولمعان يجري على طول الحدود، وظل ناعم يتكيّف مع ما خلفه.

## المزايا

- **كل التطبيقات.** يقرأ GlassBell إعلامات جميع التطبيقات (مستمع إعلامات Windows) ويعرضها في لافتاته الخاصة، حتى أربع لافتات فوق بعضها في وقت واحد.
- **زجاج حقيقي ترسمه بطاقة الرسومات.** انكسار عند الحواف، وتشتت لوني، ولمعان، ولون وظل يتكيّفان تلقائيًا. أربعة مستويات للجودة، وخلفية حية اختيارية تتبع ما خلف اللافتة حتى وهي تتحرك.
- **بمعدل تحديث الشاشة.** تلتقط بطاقة الرسومات صورة الشاشة خلف اللافتات بنفسها وترسمها دفعة واحدة، فيواكب الزجاج شاشة بتردد 60 أو 144 أو 240 هرتز (أو أكثر) ويبقى المعالج شبه خامل. وما زال العرض الكلاسيكي من الإصدار 1.0 موجودًا في الإعدادات، ويتولى الأمر تلقائيًا إذا لم تستطع بطاقة الرسومات ذلك.
- **إغلاق لافتة واحدة أو الكل.** تظهر علامة × مستديرة فوق زاوية اللافتة التي تحت المؤشر فتغلقها، ومع لافتتين أو أكثر يظهر تحتها زر **إغلاق الكل**. وهو موجود أيضًا في قائمة علبة النظام، وفي الأمر `GlassBell.exe --close-all`.
- **سريع.** تظهر اللافتة على الشاشة بعد 30–60 مللي ثانية من وصول الإعلام (قيس على حاسوب المطوّر).
- **النقر يفتح المصدر.** النقر على اللافتة يفتح ما يشير إليه الإعلام، تمامًا كالنقر على إعلام Windows نفسه.
- **الصوت.** ثلاث نغمات مركّبة في الشيفرة (بلا ملفات صوتية)؛ ويمكن أن يتبع مستوى الصوت صوت النظام.
- **إعدادات مع معاينة حية**، وأيقونة في علبة النظام، وتشغيل مع بدء Windows.
- **20 لغة.** تتبع الواجهة لغة عرض Windows (وتظهر بالإنجليزية إن لم تكن اللغة منها)، أو اللغة المختارة أسفل الإعدادات.
- **خفيف.** لا يستهلك شيئًا يُذكر وهو خامل، ونسبة مئوية قليلة من نواة معالج واحدة أثناء ظهور اللافتات، ونحو 100 ميغابايت من الذاكرة، حتى بعد مئات اللافتات (قيس على حاسوب المطوّر).

## التثبيت

1. نزّل **GlassBell-Setup.exe** من [Releases](https://github.com/vibegineer/GlassBell/releases/latest) وشغّله. لا حاجة إلى صلاحيات المسؤول.
   برنامج التثبيت غير موقّع رقميًا، لذلك قد يعرض SmartScreen رسالة «قام Windows بحماية الكمبيوتر»: انقر **مزيد من المعلومات ← التشغيل على أي حال**.
2. شغّل وضع **عدم الإزعاج** (الإعدادات ← النظام ← الإعلامات)، حتى لا تظهر لافتات Windows بجانب لافتات GlassBell. تبقى الإعلامات تصل أثناء تشغيل عدم الإزعاج، ويبقى GlassBell يراها.

الأيقونة بجانب الساعة تفتح الإعدادات. لإزالة GlassBell: الإعدادات ← التطبيقات ← التطبيقات المثبتة ← GlassBell ← إلغاء التثبيت.

**المتطلبات:** Windows 11 بإصدار 64 بت. كل ما عدا ذلك (‎.NET Framework 4.8، وDirect3D 11) جزء من Windows.

## سطر الأوامر

يستطيع GlassBell أيضًا عرض لافتات لنصوصك البرمجية الخاصة:

</div>

```
GlassBell.exe --title "Build finished" --body "All 214 tests passed" --app "CI"
```

<div dir="ltr">

| الأمر | ماذا يفعل |
|---|---|
| `GlassBell.exe` | يشغّل GlassBell عند الحاجة ويفتح الإعدادات |
| `--title T --body B [--app A] [--app-id AUMID] [--seconds S]` | يعرض لافتة (يأخذ `--app-id` أيقونة تطبيق مثبّت) |
| `--test` | يعرض لافتتين للتجربة |
| `--close-all` | يغلق كل اللافتات على الشاشة |
| `--settings` / `--quit` | يفتح الإعدادات / يغلق GlassBell |
| `--install` / `--uninstall` | يشغّل / يوقف التشغيل مع بدء Windows (لنسخة تُستخدم دون برنامج التثبيت) |
| `--stats` | يكتب في السجل مقدار الذاكرة التي تستخدمها النسخة العاملة |

</div>

## الملفات

</div>

<div dir="ltr">

| ماذا | أين |
|---|---|
| البرنامج | `%LOCALAPPDATA%\Programs\GlassBell` |
| الإعدادات | `%APPDATA%\GlassBell\settings.ini` |
| السجل | `%LOCALAPPDATA%\GlassBell\log.txt` |

</div>

<div dir="rtl">

تُحفظ اللغة المختارة في الإعدادات داخل الملف `settings.ini` في شكل `lang=ar` (أو أي رمز آخر من المجلد `lang/`)؛ والقيمة `lang=auto` تتبع لغة Windows.
ووجود ملف باسم `portable.flag` بجانب `GlassBell.exe` يجعل الإعدادات والسجل يُحفظان في مجلد البرنامج نفسه.

## البناء

</div>

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

<div dir="rtl">

يبني هذا الأمر `bin\GlassBell.exe` و`dist\GlassBell-Setup.exe` بمترجم C# الموجود في .NET Framework المرفق مع Windows: بلا SDK، وبلا NuGet، وبلا Visual Studio.

</div>

<div dir="ltr">

| المجلد | محتواه |
|---|---|
| `src/` | البرنامج: اللافتات، والعرض على بطاقة الرسومات (`GpuEngine.cs` و`Dx.cs`)، والعرض الكلاسيكي للزجاج، والتقاط الإعلامات، والإعدادات، والنغمات |
| `setup/` | برنامج التثبيت وإلغاء التثبيت |
| `lang/` | نصوص الواجهة، ملف لكل لغة |
| `assets/` | الأيقونة |
| `tools/` | نصوص الاختبار والقياس المستخدمة أثناء التطوير، ومولّد الأيقونة |

</div>

## الترجمات

الترجمات، ومنها هذه الصفحة، أُنجزت بالذكاء الاصطناعي، ولم يُتحقق منها إلا من حيث الاكتمال واتساع المكان، ولم يراجعها متحدثون أصليون. التصحيحات مرحّب بها: كل لغة ملف نصي واحد في [`lang/`](lang)، والملف [`lang/en.txt`](lang/en.txt) يشرح كل سطر.
